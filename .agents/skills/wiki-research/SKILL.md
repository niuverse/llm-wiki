# Wiki 自动研究

这是 Codex 执行的研究技能，不是无人值守服务或纯脚本研究器。遵守仓库 `AGENTS.md`；一次 `research <topic>` 或 `refresh <topic>` 已授权搜索和本地整合，无需逐篇批准。发布、定时任务和外部账号写入不在此授权内。

## 确定本轮范围

读目录、总览、研究问题和相关页面。把主题分成有限的问题维度，列出已有来源、待补机制和优先级。例如具身世界模型可按表示、动力学学习、规划／策略接口、闭环评测组织；仿真可按物理、资产、控制、感知、验证组织。优先覆盖关键维度，再增加论文数量。

已有用户范围、预算和偏好时直接沿用；宽泛请求则声明本轮边界后继续，不声称能收录“全部知识”。默认选择足以覆盖关键缺口的一批可完整阅读的来源，通常 6–10 份；成熟资料可复用，未覆盖部分进入对应研究专题的未解问题。若重要资料无法获取，保留缺口并继续其他维度。

## 搜索、归档与阅读

- 搜索使用网络工具，优先教材、原始论文、作者／机构页面、官方文档和代码仓库。按覆盖需要兼顾基础、近期进展、实现和独立评测；不能把新日期当作高质量，也不能只收录综述的引用清单。
- 打开原始资料核实标题、作者、日期、版本与结果适用范围。通过规范 URL、论文标识／版本和已有 `source_file` 去重；同一论文 PDF、项目页与仓库的用途不同，不重复计为独立证据。
- 将选定的原始字节保存到 `raw/` 新文件，保留 URL、获取时间、版本和 SHA-256。用 `tools/archive_source.py` 归档；它不搜索或解释。官方 HTML 应保存完整响应；代码快照记录 commit。无法获得全文的资料只列为候选，不编造收录页。
- 非稳定 UTF-8 Markdown 用 `uv run python tools/extract_source.py <path>` 生成缓存。完整阅读；提取缺页、公式或表格损坏时检查原 PDF／HTML，而不是据坏缓存推导。

归档接口（日期使用用户时区，版本按原始资料填写）：

```bash
python3 tools/archive_source.py --url 'https://arxiv.org/pdf/2301.04104v2' --canonical-url 'https://arxiv.org/abs/2301.04104' --slug dreamer-v3 --date 2026-10-02 --version v2 --extension pdf
```

已经下载的原始资料加 `--file /tmp/source.pdf`，仍提供原 URL；首次检查已有归档加 `--previous raw/<原文件>`。读取输出 JSON 的 `source_file`、`sha256` 和获取／版本信息。`graph/acquisitions.jsonl` 追加每次获取记录；相同内容复用文件，新内容生成带日期和校验和的文件。缓存提取使用输出的实际文件路径。

## 整合知识

每个完成阅读的新来源建来源页并追加 `ingest` 记录，带上原始文件、URL、版本／获取信息和缓存路径。保留现有页面与链接目标；版本更新优先更新原来源页的当前结论，并在正文列出新旧快照与变化，而非为每次网页变动建重复概念。

概念页按机制组织，不按论文堆摘要：定义变量、目标／约束／更新规则、假设、公式直觉、失败情形、实践影响。教学推导与例子明确标为解释；实验结论保留任务、预算、基线、时域与统计范围。结果冲突并列说明条件，不取平均或擅自消除。

按交叉主题地图互链论文／其他来源、共享概念与已有实体，学习路径提供基础顺序；主题没有强制父领域。新的单一来源项目说明并入来源页。新增链接要表达真实关系，不能为提高链接数而连线。

撰写或实质修订论文、项目解析时，读取 [references/deep-reading.md](references/deep-reading.md)，落实共享基础与论文特有机制的分工，以及项目代码核查范围。

保存一篇简短 `<topic>-research.md` 综合，记录本轮范围、维度覆盖、关键来源与结论变化；后续刷新沿用它，避免重复报告。待补问题写入对应 `wiki/topics/` 专题；`research-questions.md` 只由目录脚本汇总入口；只有综合判断改变才改总览。运行 `uv run python tools/build_catalog.py` 同步目录，再追加日志，追加 `research` 或 `refresh` 记录，标明未收录候选和证据限制。

## 刷新模式

先检查相关来源的当前规范版本及日期，再搜本轮缺口与重要后续工作。比较规范标识、版本和原始字节校验和；旧文件始终不覆盖。相同内容复用原快照，记录检查时间；字节变化可能只是网页导航，完整比对后仅将实质变化编译进知识。新版本或结论纠正保存新快照，在来源页保留历史路径与变更理由。

“没有变化”和“无法核实”要分开报告。只检查过链接或搜索标题不能把页面 `modified` 刷成今天；对知识做了实质审阅才更新语义日期。不要因为本轮资料没变化而做整库重写。

## 完成标准

运行健康检查和生产构建，修复本轮失效链接、缺失归档、目录／日志不同步及证据状态问题。报告覆盖维度、新增／复用／更新来源、实质知识变化、冲突与剩余缺口、验证结果；给出本地文件或预览链接。检查器只验证结构，研究结论仍须可追溯。完成范围内工作后停止，不自动推送或部署。
