# AgentsDock Releases

This repository is the public, read-only distribution feed for AgentsDock
desktop builds. GitHub Releases contain the signed installers, update metadata,
checksums, and release notes consumed by the in-app updater.

## Install

Download the newest installer from the
[latest release](https://github.com/ZhengyiLuo/AgentsDock-Releases/releases/latest).

## Security

- macOS releases are signed with a Developer ID certificate and notarized by
  Apple before publication.
- Published assets are immutable. A corrected build is released with a higher
  version rather than replacing an existing artifact.
- This repository does not contain application source, credentials, or user
  data.

The AgentsDock application source and the AgentsServer source are maintained in
separate repositories.
